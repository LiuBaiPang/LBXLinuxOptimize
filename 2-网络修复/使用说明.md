# 网络修复工具 —— 使用说明

## 解决什么问题

Jetson 有时候无线、有线都连不上网（时好时坏，重启有时又能好）。

## 根因（本机已确诊）

1. **WiFi 省电模式开着**（`Power save: on`）
   Jetson 无线网卡开省电后会间歇性掉线，是最常见的"WiFi 时断时续"原因。
2. **resolvconf 和 systemd-resolved 两个服务同时在管 DNS**（都指向 127.0.0.53）
   这是 JetPack 5 (Ubuntu 20.04) 的经典坑：两个服务抢着写 DNS 配置，偶尔中转一挂，
   所有域名解析全失败 → 表现为"连着 WiFi / 插着网线，但就是上不了网"。
3. **DNS 兜底是 8.8.8.8**（国内网络不可达），DHCP 偶尔拿不到 DNS 时彻底断网。

## 使用方法

1. 双击 `网络修复工具.desktop`（或 `启动网络修复.sh`，弹出提示选"运行"）
2. 程序自动诊断，日志会列出发现的问题
3. 按推荐设置（开关1开、DNS选"静态直连·阿里"）→ 点 **【应用配置】**
4. 输入登录密码，等它执行完，再点 **【刷新诊断】** 确认全部 ✓

### 各个控件的作用

| 控件 | 作用 |
|---|---|
| 开关：关闭WiFi省电 | 永久关闭无线网卡省电（防止WiFi间歇掉线），强烈推荐打开 |
| DNS下拉框：自动 | 恢复系统默认（DNS跟随路由器），未出问题时用 |
| DNS下拉框：静态直连(阿里/114/腾讯) | 绕过 127.0.0.53 中转，直接写死DNS，**根治间歇性全断**，推荐 |
| 开关：断网自动守护 | 每2分钟体检一次：断了自动重连 → 不行重启NetworkManager → DNS坏了自动重启DNS服务 |
| 【一键修复】 | 立即重启网络服务+重连所有网络+清DNS缓存（断网急救用，约10~20秒） |

## 推荐配置（一次到位）

- 关闭WiFi省电：**开**
- DNS：**静态直连·阿里DNS**
- 断网自动守护：**开**

应用一次即可，重启电脑后依然有效。

## 日常观察

守护日志在 `/var/log/aaafix-net-watchdog.log`，可用下面命令查看有没有自动修过：

```bash
tail -f /var/log/aaafix-net-watchdog.log
```

## 文件结构

- `网络修复工具.desktop` —— 双击启动的入口
- `启动网络修复.sh` —— 备用启动方式（终端运行）
- `network_fix.py` —— 图形界面（Python/tkinter）
- `actions_network.sh` —— 实际修改系统配置的 root 脚本（由界面自动调用）

所有修改前会自动备份原配置到 `/etc/aaafix/`，选"DNS:自动"应用即可完整还原。
