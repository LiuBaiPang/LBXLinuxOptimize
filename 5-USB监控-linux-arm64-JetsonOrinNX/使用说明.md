# USB 监控工具 使用说明

Jetson Orin NX (L4T R35.6.4) 上的 USB 实时监控面板,用于排查 **USB 供电不足导致的卡顿、掉线、降速** 问题。

## 功能一览

| 区域 | 内容 |
|---|---|
| USB 设备树 | 所有 USB 设备/Hub 层级,每项显示 协商速率 · 请求电流,拔插 1 秒内刷新;⚠=超预算/降速/未授权,💤=已被系统挂起 |
| 供电健康 | 板载 INA3221 电源监测芯片各通道 电压V / 电流A / 功率W;5V 欠压告警(<4.75V 橙,<4.60V 红);每条总线 Σ设备请求电流;功耗模式(nvpmodel)查看与切换 |
| 设备详情 | VID:PID、厂商/产品/序列号、USB 版本、协商速率(降速检测)、请求电流(超预算检测)、运行状态、电源策略、各接口驱动、存储读写速率、深度模式收发速率 |
| 摄像头预览 | 枚举全部 /dev/video* 节点(RealSense 一台占 6 个节点),实时画面 + FPS/分辨率/吞吐估算/读取错误计数;设备掉线会红字提示 |
| USB 事件日志 | 实时跟踪 /var/log/kern.log 的 usb/hub/xhci 事件并分级着色:红=掉线/过流/无法枚举,橙=复位/hub禁用端口(EMI) |

## 文件说明

| 文件 | 说明 |
|---|---|
| `usb_monitor.py` | 主程序(Python3 + tkinter,标准库 + 已装好的 python3-opencv,无新增依赖) |
| `usbmon_helper.py` | 深度模式 root 助手:解析 usbmon 文本流统计每设备收发字节,JSON 行输出 |
| `actions_usb.sh` | root 动作脚本(INA3221 权限修复 / jtop 服务 / 自动休眠开关 / 重新枚举 / usbmon / 功耗模式),全部幂等 |
| `启动USB监控.sh` | 启动器(双击 .desktop 或本脚本) |
| `USB监控工具.desktop` | 桌面启动入口(本目录内双击,选"运行") |

## 关键概念(读懂数字)

- **请求电流 (bMaxPower)**:设备向总线**声明**的电流上限,不是实时消耗。USB2 口预算 500mA,USB3 口 900mA。
- **供电不足的典型信号**:
  1. USB3 设备(如 RealSense 720mA)**降速**到 480M(掉到 USB2),但请求电流仍 >500mA → 超预算告警;
  2. INA3221 的 5V 输入轨电压 <4.75V(负载重/线损大);
  3. 事件日志出现 `over-current`、`disabled by hub (EMI?)`、`USB disconnect`;
  4. 同一 Hub 下挂多台高耗电设备(本机两台 RealSense 同挂在 Genesys Hub 下)。
- **实时电流**:优先看 INA3221 直读(需先点一次"INA3221读取修复");jtop 服务提供整板功率。

## 快捷操作(均需管理员密码,密码只在内存缓存,不落盘)

| 按钮 | 作用 |
|---|---|
| INA3221读取修复 | 装 udev 规则放行只读权限,之后面板能显示电压/电流/功率(免 root 常驻生效) |
| 启用jtop服务 | 开启 jetson-stats 的 jtop.service,面板可兜底读取整板功率 |
| 全部禁止USB休眠 | 所有 USB 设备 `power/control=on`(常供电,治自动挂起后掉线;重启后失效,需重打) |
| 恢复自动休眠 | 恢复系统默认 `power/control=auto` |
| 启用usbmon模块 | 加载 usbmon 并设开机自动加载(深度模式前置条件) |
| 深度模式 | sudo 起一个 usbmon 解析进程,**实时显示每设备 RX/TX 速率** |
| 重新枚举此设备 | 设备卡死时 authorized 0→1,相当于不拔线的"重插" |
| 禁止/允许此设备休眠 | 只对选中设备改电源策略 |

## 技术说明与故障排查

- 数据全部来自 sysfs(/sys/bus/usb)、/proc/diskstats、/var/log/kern.log,普通用户即可读;**只读监控完全不需要 root**。
- 事件日志读的是 kern.log(用户在 adm 组);dmesg 因 `dmesg_restrict=1` 免 root 不可用,不影响本工具。
- 摄像头预览用 OpenCV(V4L2),640x480;预览限 ~14fps 以免抢占总线带宽。读不出画面 → 换下一个 video 节点。
- 深度模式没有数据?先点"启用usbmon模块";仍不行说明内核未编 USB_MON(本机已确认存在 `usbmon.ko`,正常)。
- 撤销 INA 放权:`sudo bash actions_usb.sh ina-readundo`。
- 自动化冒烟:`AAAFIX_SMOKE=1 ./启动USB监控.sh` 打印一轮快照 JSON 后退出,不开窗口。
- 本目录由 aaafix-autosync 每 15 秒自动 git 同步,请勿放入敏感文件。
