# 3-快捷截图

按 **Shift + Alt + S** 框选屏幕区域 → 自动**复制到剪贴板**（可直接去微信/浏览器/WPS 里 Ctrl+V 粘贴），同时自动保存一份到 `~/Pictures/截图/`。

## 使用

| 操作 | 效果 |
|---|---|
| **Shift + Alt + S** | 框选区域截图 → 复制 + 保存（鼠标变成十字，拖拽选区，Esc 取消） |
| 完成后 | 屏幕右上角弹出通知"截图完成"，文件在 `~/Pictures/截图/截图_日期_时间.png` |

## 文件说明

| 文件 | 作用 |
|---|---|
| `截图复制.sh` | 主脚本，带 3 种模式：`area`（框选，默认）/ `full`（全屏）/ `window`（当前窗口） |
| `安装快捷键.sh` | 注册 Shift+Alt+S 到 GNOME（可重复执行，立即生效，无需重启） |
| `卸载快捷键.sh` | 卸载快捷键，恢复原状 |

## 其它截图模式

```bash
./截图复制.sh full     # 全屏
./截图复制.sh window   # 当前活动窗口
```

想给它们也加快捷键：打开 设置 → 键盘 → 自定义快捷键，命令分别填
`"/home/jsz/AAAFIXsystem/3-快捷截图/截图复制.sh" full` 和 `... window`。

## 修改快捷键

编辑 `安装快捷键.sh` 里的 `BINDING="<Alt><Shift>s"` 一行（如改成 `"<Ctrl><Alt>a"`），重新运行即可；或在 设置 → 键盘 里改。

## 技术说明 / 故障排查

- 抓图用系统自带 `gnome-screenshot`；复制剪贴板用系统自带 Python GTK（**不需要安装 xclip**）。
- 复制完成后脚本立即返回；后台会留一个很小的 Python 进程为剪贴板供图（本机无剪贴板管理器，进程退出剪贴板就没了），在你复制新内容或 30 分钟后自动退出，属正常现象。
- 仅适用于 X11 会话（本机即 X11）；Wayland 会话不适用。
- 快捷键不生效时：先运行 `./安装快捷键.sh` 重新安装一次；仍不行则注销重新登录。
- 想确认是否注册成功：
  ```bash
  gsettings get org.gnome.settings-daemon.plugins.media-keys custom-keybindings
  ```
