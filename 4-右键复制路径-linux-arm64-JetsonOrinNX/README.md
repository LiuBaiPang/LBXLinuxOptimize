# 4-右键复制路径-linux-arm64-JetsonOrinNX

在 **文件(Nautilus)** 里右键任意文件/文件夹 → 点 **复制完整路径** → 该文件完整路径进入剪贴板,可直接 Ctrl+V 粘贴。

支持多选(复制多个完整路径,每行一个),支持中文和带空格的文件名。

## 使用

| 操作 | 效果 |
|---|---|
| 右键文件 → **复制完整路径** | 复制该文件完整路径(一级菜单,推荐档) |
| 右键空白处 → **复制当前文件夹完整路径** | 复制当前打开的文件夹路径 |
| 降级档没有一级菜单时 | 右键 → **脚本** → 复制完整路径 |

## 安装 / 升级 / 卸载

```bash
./安装.sh    # 在自己终端里运行(会提示输 sudo 密码装 python3-nautilus)
./卸载.sh
```

两档效果:

| 档位 | 菜单位置 | 条件 |
|---|---|---|
| A 一级菜单(推荐) | 右键直接出现"复制完整路径" | 装了 `python3-nautilus` + `gir1.2-nautilus-3.0` |
| B 免装包降级 | 右键 → 脚本 → 复制完整路径 | 无法用 sudo 装包时自动降级 |

如果安装时没能输 sudo 密码(比如从别的工具里调用的),脚本会自动装降级档并提示;
之后在终端跑一次下面两条即可升级到一级菜单:

```bash
sudo apt-get install -y python3-nautilus gir1.2-nautilus-3.0
"/home/jsz/AAAFIXsystem/4-右键复制路径-linux-arm64-JetsonOrinNX/安装.sh"
```

(装好后 `安装.sh` 会自动移除降级档,避免菜单里出现两份。)

## 文件说明

| 文件 | 作用 |
|---|---|
| `复制路径扩展.py` | nautilus-python 扩展(一级菜单档),部署到 `~/.local/share/nautilus-python/extensions/` |
| `复制完整路径.sh` | Nautilus 右键脚本(降级档),部署到 `~/.local/share/nautilus/scripts/复制完整路径` |
| `安装.sh` | 部署 + 自动装依赖 + 重启 Nautilus,可重复执行 |
| `卸载.sh` | 两档一起移除 |

## 技术说明 / 故障排查

- 剪贴板用系统自带 Python GTK(和 3-快捷截图 同一套做法),**不需要 xclip**;仅适用 X11 会话(本机即 X11)。
- 一级菜单档:剪贴板内容由 Nautilus 进程持有,Nautilus 退出(如 `nautilus -q`)后剪贴板内容会丢;降级档脚本自己驻留一个小进程供图(复制新内容或 30 分钟后自动退出),同 3-快捷截图。
- 菜单不出现时:重新运行 `./安装.sh`;仍不行则注销重新登录。
- 桌面(壁纸)上的右键属于桌面图标扩展(ding),不走 Nautilus 菜单,本工具不含;进文件夹内右键即可。
- 回收站/网络位置里的文件没有本地路径,会复制它的 URI 形式。
