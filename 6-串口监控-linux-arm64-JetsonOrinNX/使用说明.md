# 6-串口监控-linux-arm64-JetsonOrinNX

Jetson Orin NX(L4T R35.6.4)串口监控 / 控制与飞控(MAVLink)连接工具。

## 功能一览

| 页面 | 功能 |
|---|---|
| 串口总览 | 扫描 `/dev` 全部串口(ttyAMA0/ttyTHS*/ttyTCU0/ttyACM*/ttyS* 等),显示类型/硬件来源/权限/占用状态/硬件活动(内核中断增量,不动设备即可知道有没有数据流);选中可开 HEX+ASCII 实时预览 |
| 串口终端 | 完整串口控制台:波特率 1200~4M、数据位/校验/停止位/流控;收发(文本/HEX)、行尾、定时发送、发送文件、保存日志 |
| 飞控 MAVLink | 连接 PX4 / ArduPilot 飞控:心跳、飞行模式、解锁状态、电压/电流/电量、姿态、高度、GPS、HUD 实时遥测;发送指令:切模式、解锁/上锁(双重确认)、请求数据流、Ping、读参数、原始 COMMAND_LONG;STATUSTEXT 飞控日志窗 |
| 资料 | 40-pin 串口引脚速查 + 一键释放/恢复 40-pin UART + 打开完整《资料手册.html》 |

配套《资料手册.html》(浏览器打开):40 针彩色引脚图、每个串口的
**针脚定义 → 一般用法 → 原文链接 → 示例** 四段式说明、飞控接线教程、故障排查表。

## 快速操作

```bash
# 启动
./启动串口监控.sh

# 冒烟测试(不开窗, 打印设备快照 JSON)
AAAFIX_SMOKE=1 ./启动串口监控.sh

# MAVLink 模块自测
python3 mavlink_min.py

# 查看 40-pin 串口占用状态(只读)
./serial_actions.sh status
```

### 连接飞控(你已插 USB 的 PX4)

1. 打开工具 →「飞控 MAVLink」页 → 端口选 `/dev/ttyACM0`(已自动选中)→ 115200 → **连接**。
2. 几秒内出现心跳,卡片显示模式/电量/姿态;USB 直连不挑波特率,连不上就点【自动嗅探波特率】。

### 把飞控接到 40-pin 排针(装机)

1. 接线:**脚8(TX)→飞控RX,脚10(RX)→飞控TX,脚6(GND)→飞控GND**,电源脚不接。
2. 「资料」页 →【释放40-pin串口】(输一次密码)→ **重启**。
3. MAVLink 页选 `ttyAMA0`,波特率与飞控一致(常见 57600/115200),连不上先回环测试(手册第 3 节)。

## 权限说明

- 只读功能(总览/扫描)免 root;
- `ttyTHS*`、`ttyACM*`(usb CDC)属于 dialout 组,**jsz 用户可直接读写**;
- `ttyAMA0`(40-pin)出厂 root:tty 且被控制台/getty 占用 → 用【释放40-pin串口】(改
  extlinux.conf、停用 getty、加 udev 规则,均幂等,`restore-40pin` 可完整还原);
- 改类操作走 `sudo -S` 调 `serial_actions.sh`,密码只在内存缓存、不落盘。

## 安全警告 ⚠️

- **解锁(ARM)前**:确认桨叶周围无人、手不碰遥控器油门、场地开阔。解锁按钮有两层确认,
  但**飞控收到指令就真的会转**,请当作真枪实弹。
- **预览功能会消费串口数据**:飞控正在用的口别开预览(工具会弹警告)。
- **接线三铁律**:TX↔RX 交叉、GND 必须共地、别乱接电源脚;40-pin 是 3.3V 电平,
  严禁接 5V 电平信号。

## 故障排查

| 症状 | 处理 |
|---|---|
| 完全收不到数据 | 回环测试 → 查共地 → 自动嗅探波特率 → 确认 40-pin 已释放 |
| 有数据但乱码 | 波特率/校验位/停止位不对;或共地不良 |
| MAVLink 一直"等待心跳" | 口选错 / 波特率不对 / 飞控口没配 MAVLink / 未释放导致日志污染数据流 |
| ttyAMA0 报"无权限"或"忙" | 【释放40-pin串口】并重启 |
| 飞控拒绝解锁 | 看 STATUSTEXT 红色行,飞控会说明原因(罗盘/GPS/ESC 检查未过等) |

完整排查表见《资料手册.html》第 7 节。
